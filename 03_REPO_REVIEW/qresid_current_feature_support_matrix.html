qresid Current Feature Support Matrix

Live feature/status matrix. Date: 2026-05-10. Source: inverse Gaussian, expanded fweight, NB2 offset/exposure, NB variants, zero-inflated count, grouped-binomial/binreg validation cycle and Hilbe/count model coverage reconciliation.

This page answers what is ready, what is experimental, what is diagnostic-only, what is missing, and whether any missing item puts the current package validity in doubt.

Read this together with the GLM/link report. EXPERIMENTAL_VALIDATED_SEPARATE_BENCHMARK means a route is supported or experimental in qresid, but detailed evidence lives in another active benchmark. GATED_VARIANT means a specific variant remains unclaimed; it does not cancel a validated base route.

Cross-report rule: this support matrix is the quick answer to “what can I use?” The GLM/link report shows evidence_scope and evidence_artifact so you can tell whether evidence was generated in that report (THIS_REPORT) or validated separately (SEPARATE_BENCHMARK). The reports are complementary, not competing authorities.

Count roadmap rule: the unified extension matrix says what exists in official Stata, what would need external Hilbe/SSC/Stata Journal research, and what validation type is required next. It does not expand support claims by itself.

Validity summary. Current local extension prerelease validity is acceptable. BLOCKS_CURRENT_VALIDITY: none. BLOCKS_PUBLIC_RC: pweight public policy. Missing Tweedie, official truncated/censored/specialized count routes, external Hilbe-style count models, mixed models, svy:, aweight, iweight, glm nbinomial ml, and unsupported weighted routes do not invalidate the package because current public docs do not claim support for them.

Footnote. PIT transforms an observation through the fitted CDF to the uniform scale. RQR/Dunn-Smyth residuals transform that PIT value to normal scale with invnormal(). For discrete outcomes, F_low and F_high define the CDF jump around the observed value. uvar() supplies the same uniform draws to Stata and R for exact discrete residual benchmarking.
