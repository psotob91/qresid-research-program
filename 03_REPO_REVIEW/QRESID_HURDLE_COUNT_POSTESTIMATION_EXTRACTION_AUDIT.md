## Parameter Mapping

For `hplogit`, the evaluator uses:

- zero probability `pi0 = invlogit(xb_logit)`;
- positive count distribution: zero-truncated Poisson with `mu = exp(xb_poisson)`.

For `hnblogit`, the evaluator uses:

- zero probability `pi0 = invlogit(xb_logit)`;
- `a = exp(/lnalpha)`;
- evaluator parameter `mu_eval = exp(xb_negbinomial) * a`;
- NB size `theta = 1/a`;
- NB probability `prob = 1/(1 + mu_eval)`;
- positive distribution: zero-truncated NB with base zero probability
  `(1 + mu_eval)^(-1/a)`.

`pscl::hurdle` fits the same count parameters in the tested routes, but its
zero equation is oriented toward crossing the hurdle. Therefore the `pscl`
zero-equation coefficients match the negative of the pinned Stata logit
equation.
