## Changes

- Simplified `qresid/README.md` so the manual appears once, in a clearer
  Start/Tutorials/Reference structure.
- Moved validation detail out of the README body and kept a concise link to
  `docs/validation.md`.
- Expanded the statistical background to emphasize the practical diagnostic
  advantage: many fitted distributions can be inspected on one approximate
  normal residual scale.
- Added tutorial material for:
  - Pearson/deviance versus quantile residuals in Bernoulli data.
  - Link comparison for Bernoulli models.
  - Functional-form detection with a nonlinear binary mean.
  - Underdispersed counts with Poisson, negative binomial and generalized
    Poisson comparisons.
- Added `qresid/docs/link-functional-form.md`.
- Extended `qresid/docs/scripts/build_manual_assets.do` to generate the new
  figures and selected output excerpts.

## Visual Iterations

1. Generated first binary residual comparison candidates. Pearson and deviance
   Q-Q plots showed the expected two-branch behavior; quantile residuals gave a
   clearer normal-scale diagnostic.
2. Generated raw nonlinearity residual plots. Raw scatter was too noisy for a
   teaching example.
3. Added binned residual summaries for the nonlinearity example. These made the
   misspecified linear logit pattern visible and reduced noise after adding the
   quadratic term.
4. Tried an extreme underdispersed count simulation. The generalized-Poisson
   CDF endpoint check correctly rejected an unstable fit.
5. Replaced the count simulation with a gentler binomial-generated
   underdispersed count example. The manual asset build then passed and the
   generalized-Poisson Q-Q plot showed a clearer didactic improvement.
