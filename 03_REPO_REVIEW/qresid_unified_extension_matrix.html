Status source: Hilbe/count model coverage plan, support matrix, registry, 2026-05-10.

How To Read This

This matrix is a roadmap, not a public support claim. It separates official Stata commands, external/Hilbe-style models, current qresid support, R benchmark feasibility, and whether missing support affects the validity of the current package.

The support matrix remains the quick answer to "what can I use now". This unified matrix answers "what exists, what is missing, and what validation would be required next".

Validity Summary

No missing Hilbe/count model listed here is a BLOCKS_CURRENT_VALIDITY item. A route becomes blocking only if public docs claim support or a critical benchmark for a claimed route fails. Public RC must still review policy-sensitive experimental routes such as direct [pweight=].
